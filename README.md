# Clínica Olívia Salles

Peça conceitual de portfólio para uma clínica de estética fictícia, construída com React, TypeScript, Vite e Tailwind CSS 4.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm test
npm run lint
npm run build
```

## WhatsApp

Copie `.env.example` para `.env.local` e informe `VITE_WHATSAPP_NUMBER` com DDI e DDD, apenas dígitos. Sem a variável, o site abre o seletor de contatos do WhatsApp com a mensagem preenchida.

Todos os nomes, perfis, depoimentos, resultados, contatos e endereços apresentados no site são fictícios.
